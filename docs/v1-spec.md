# GoTikTok V1 规格（V1 Spec）
> 本文档为 GoTikTok 的 **V1 规格文档（功能规格说明）**：V1 功能点、边界与验收标准以本文档为准；迭代计划附于第三节。
> 依据：`docs/decision-log.md`（全部决策经用户确认）+ 2026-08-11 用户确认的 V1 细节。

---

## 一、概述

- 定位：仿照 TikTok 的视频分享平台；面向小范围使用（几百到上千人）。
- V1 范围：**视频上传/播放、点赞、评论** + 用户名密码登录（关注 = V2 排除项）。
- 合规：匿名昵称即可；小范围试运行形态，无公开商用合规要求（无实名认证/内容审核/等保要求）（口径见 `docs/decision-log.md` 项目定位，2026-09-08）
- 技术约束（详见决策台账）：React + Vite + TS 前端；Go + Gin + GORM 后端；MySQL（Redis V1 不引入）；视频原文件直传阿里云 OSS、不转码；无管理后台、无监控。

## 二、功能点清单

### F1 用户注册

- 【功能描述】任意用户可用「用户名 + 密码」注册，注册即获得匿名昵称（默认取用户名），无需管理员介入。
- 【边界/异常】
  - 用户名唯一，重复注册返回明确错误
  - 密码有强度下限（长度下限），过弱拒绝并提示
  - 密码不落明文（服务端哈希存储）
- 【验收标准】
  1. 用新用户名注册成功，返回成功并可立即登录
  2. 用已存在用户名注册，返回「用户名已存在」错误
  3. 密码过弱（短于下限）注册被拒绝并提示原因
  4. 数据库中看不到明文密码

### F2 用户登录

- 【功能描述】用户名 + 密码登录，成功后获得会话凭证（**双 token：短命 access + 长命 refresh**，2026-08-29 确认），后续请求携带凭证。
- 【边界/异常】
  - 用户名或密码错误：返回统一错误提示（不区分具体哪一项错，避免账号探测）
  - access token 过期：前端用 refresh token 静默续期，用户无感；refresh token 过期后需重新登录
  - 未携带凭证访问需登录接口：返回 401
- 【验收标准】
  1. 正确用户名 + 密码登录成功，返回 access + refresh 双凭证
  2. 错误密码登录失败，返回错误提示
  3. 不存在的用户名登录失败，返回与错误密码相同的提示
  4. 携带有效 refresh token 刷新成功，获得新的 access + refresh 双凭证
  5. 旧 refresh token 再次用于刷新被拒（轮换生效，401）
  6. refresh token 过期后刷新被拒（401），需重新登录
  7. 未携带凭证访问需登录接口被拒（401）
- 【测试前提】token 有效期（access 2h / refresh 7d）必须可配置，集成测试用秒级有效期验证过期与轮换场景，避免等待真实时长

### F3 视频上传

- 【功能描述】登录用户上传视频：直传阿里云 OSS（不转码），上传后生成视频记录供播放。
- 【边界/异常】
  - 单文件 ≤ 500MB，超限拒绝并提示
  - 格式限制：白名单与接口契约一致（mp4 / mov / webm / m4v / avi / mkv），不在白名单拒绝
  - 未登录不可上传
  - 上传失败可重试，不产生脏数据
- 【验收标准】
  1. 登录后上传 ≤500MB 合法格式视频成功，视频出现在列表中
  2. 上传 >500MB 文件：①申请凭证时被服务端拒绝并提示超限；②构造 >500MB 上传直传 OSS（绕过服务端预检），OSS 侧拒绝（policy `content-length-range` 生效）
  3. 上传白名单外格式（如 .exe）被拒绝并提示
  4. 未登录上传被拒绝（401）
  5. 上传中断/失败后重试成功，无重复或残缺记录

### F4 视频播放

- 【功能描述】视频列表 + 播放页：展示视频（含描述/作者/点赞数/评论数），可播放。
- 【边界/异常】
  - 视频不存在：返回明确错误
  - 视频记录存在但源文件不可用：给出错误提示而非白屏
  - 未登录可浏览列表与播放页（公开访问，无需鉴权）
- 【验收标准】
  1. 列表展示视频并可进入播放页正常播放
  2. 访问不存在的视频返回明确错误
  3. 播放页展示作者、点赞数、评论数

### F5 点赞

- 【功能描述】登录用户可对视频点赞/取消点赞（可反复切换），展示点赞计数。
- 【边界/异常】
  - 未登录不可点赞（401）
  - 重复点击幂等：同一用户重复点赞不产生重复记录
  - 计数直接读库实时统计（V1 不引入 Redis 缓存）
- 【验收标准】
  1. 点赞后计数 +1，取消后计数 -1，可反复切换
  2. 同一用户连续点赞多次，计数只 +1
  3. 未登录点赞被拒绝（401）

### F6 评论

- 【功能描述】登录用户可发表评论，作者可删除自己的评论，展示评论列表。
- 【边界/异常】
  - 未登录不可发表
  - 只能删除自己的评论，删他人评论被拒绝
  - 评论内容非空
- 【验收标准】
  1. 登录后发表评论成功，评论出现在列表
  2. 作者删除自己的评论后，评论从列表消失
  3. 删除他人评论被拒绝
  4. 未登录发表评论被拒绝（401）
  5. 空评论被拒绝

## 四、已确认问题（按确认时间归档）

1. **未登录可浏览视频**（2026-08-18）：列表/播放页公开可访问，无需鉴权；点赞、评论仍要求登录（401）
2. **视频列表排序**（2026-08-18）：默认按发布时间倒序
3. **点赞计数**（2026-08-18）：直接读库实时统计；**V1 前期不引入 Redis**，待 V1 全部功能完成后视需要再评估
4. **双 token 认证**（2026-08-29）：access token = JWT（2 小时【默认值】，不落库）；refresh token = 随机串（7 天，SHA-256 哈希落库，逐次轮换）；多设备独立会话、不互踢。详见接口契约「认证模型」一节
5. **JWT 有效期**（2026-08-29）：refresh 侧 7 天（沿用既有确认值）；access 侧 2 小时为默认值，实现前可调
6. **会话窗口模式**（2026-08-29）：三方案比选后定为**固定 7 天、不随刷新滑动**——
   - 固定窗口：被盗凭证最多再活 7 天，自动止损；V1 无登出接口、多设备不互踢，固定窗口是被盗后**唯一的自动止血线**；实现最小。代价：活跃用户每 7 天需重新登录一次
   - 纯滑动窗口（轮换时延长过期时间）：活跃用户不掉线，但去掉止损线，且 V1 应配套补登出接口
   - 滑动 + 30 天绝对上限：体验/安全折中，实现量居中
   - **选定固定窗口**：小范围使用场景安全止损优先、7 天重登一次可接受；后续若改滑动或加上限，表结构兼容（见 `docs/database-design.md`「演进备注」）
7. **视频描述文案**（2026-08-29 归档）：上传时可选填、最长 140 字、留空不展示——已随 `docs/api-contract.md` 接口 5/6 定稿落实（可选字段、≤140 字、留空存 NULL），无需再确认

**迭代内待确认小项**（实现前确认，不擅自决定）：无——历史挂起项已全部归档（见第 7 条）
