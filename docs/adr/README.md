# GoTikTok 架构决策记录（ADR）

本目录存放架构决策记录（Architecture Decision Record）：一条重大决策一个编号文件。

- 命名：`NNNN-<短描述>.md`（四位序号从 0001 起）
- 格式：背景 / 备选方案 / 决策结果 / 理由 / 影响与后果
- 新增 ADR 后须同步更新 `docs/decision-log.md`（台账只记结论，ADR 记比选过程）

> 首篇 ADR（0001 双 token 认证 + 固定会话窗口）计划于迭代 1 实现认证时编写——
> 届时实现中暴露的细节可一并记录；比选结论先行记录于 `docs/v1-spec.md` 第四节。
